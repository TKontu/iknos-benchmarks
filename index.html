Local LLMs on the Iknos evidence-reasoning tasks

Abstract. Six locally served LLM configurations are evaluated on five tasks of the Iknos pipeline (claim extraction, negation canonicalisation, entity extraction, claim–span verification, evidence–hypothesis sign judgement) and on ingest throughput. Each task uses its production prompt and output schema. Test sets, acceptance criteria and the selection rule were fixed before candidate evaluation; results are reported as Wilson 95% intervals.

Protocol

Test sets frozen before candidate evaluation (SHA-256 below); confirmation sets unread at registration. Amendments 11–15 followed the incumbent screen and preceded candidate evaluation. R5 reference labels: unanimous agreement of a three-model panel, filtered by independent adjudication against a pre-specified rubric. Source corpus private; aggregates only.

Evidence-judge method on the selected model

Pre-registered 2026-10-12 · results 2026-10-13

Five ways to run the R5 evidence judge on Qwen3.8-27B (llama.cpp, Q4_K_XL, two RTX 3090 replicas). Accuracy on the frozen R5 sets above; speed and stability on all 3,248 candidate pairs of a 10-document test corpus, each method run twice.

Sign accuracy with its Wilson 95% lower bound; every method gets exactly the same items right (paired McNemar against A: p = 1.0, Holm-corrected). Rival credit: evidence wrongly credited to a rival hypothesis.

Result: equal accuracy; one probability-scored call (B) is ~4× faster than the 5-sample panel and ~12× more stable run to run. Approved as the production judge.
